# -parking-management-system
C++ parking management system using OOP concepts: inheritance, polymorphism, STL and exception handling.

## Features
- Vehicle entry and exit management
- Automatic billing based on parking duration
- Support for multiple vehicle types
- Real-time parking spot availability
- Full parking history and reports

## Technologies Used
- C++ (Object-Oriented Programming)
- Visual Studio (MSVC)
- STL (Standard Template Library)

## OOP Concepts Applied
- **Inheritance** - Base Vehicle class with derived types
- **Polymorphism** - Virtual methods for vehicle behavior
- **Encapsulation** - Private/protected class members
- **Exception Handling** - Custom parking exceptions
- **Operator Overloading** - `==` and `<<` operators

## Vehicle Types
- **Voiture** (Car) - 10 DH/hour
- **Moto** (Motorcycle)
- Other vehicle types

## How to Run
1. Open `GestionParking.sln` in Visual Studio
2. Build the solution (Ctrl + Shift + B)
3. Run the project (Ctrl + F5)
